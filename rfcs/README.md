# RFCs

Substantive changes to `spec/BLUEPRINT-v1.0.md` or `spec/SPEAK-v1.0.md` proceed by RFC.

Copy `0000-template.md`, number it sequentially at the time the pull request opens, and open the pull request. The comment period is 30 days. MAJOR changes require a two thirds supermajority of listed authors. MINOR and PATCH changes require one approving author review.

Editorial changes that do not alter a requirement do not need an RFC.
