# Profile: Individual Brain

A starting configuration for one person. Non normative. Every element is intended to be changed by the owner.

## Charter defaults

```yaml
tier: 1
layers: [0, 1, 2, 3, 6]
owner: { kind: individual }
```

Target Tier 1 and stay there deliberately. Most of the value of a brain arrives in Phase 4, capture, and gates added before there is anything worth gating become 44 pending approvals nobody reads.

## Topology

One domain per counterparty or life area. A domain is not a topic, it is a relationship or a standing commitment. A shared entity layer holds people, organizations, and tools that appear in more than one domain, so that a fact about a person is written once.

## Growth path

| When | Move to |
|---|---|
| You are producing work others read | Phase 6, classification, and Tier 2 |
| You are drafting with agents | Phase 8, agency |
| You are contributing into an organization brain | Phase 9, boundary, and Tier 3 |

## What to skip at first

Boundary, operations, and agent charters. They are real requirements later and dead weight now.
